# Surprise

Open the site and you get one thing: the finger-heart emoji, full screen.

Repository: [github.com/MostafaMosaad2/Surprise](https://github.com/MostafaMosaad2/Surprise)

## Run locally

```bash
npm install
npm run dev
```

Then open [http://127.0.0.1:43141](http://127.0.0.1:43141).

## Deploy on Vercel

1. Open [Import Surprise into Vercel](https://vercel.com/new/import?s=https://github.com/MostafaMosaad2/Surprise).
2. Sign in with GitHub if Vercel asks.
3. Set the project name to **surprise-heart** if **surprise** is already taken.
4. Deploy. After that, every push to `main` publishes automatically.
